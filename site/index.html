pi install npm:@lightninglabs/pi-402

export L402_PROXY_URL=https://lampo.run/v1
export PI402_NETWORK=mainnet
export PI402_WALLET_PASSWORD='choose-your-own-strong-password'

pi

/model pi402/deepseek-v4-flash # or pi402/glm-5.2, pi402/kimi-k3.1-pro, pi402/kimi-k3

On mainnet the pi402 wallet needs your own password and a seed you back up; see the pi-402 install guide. DeepSeek V4 Flash bundles fit pi402's default limits, so it works without raising PI402_MAX_SAT_PER_REQUEST. Keep at least 2,000 sats in the wallet: after a payment the Wavelength wallet must keep either zero or at least 1,000 sats of change.

Models and prices

One payment buys a bundle of tokens; each request is debited by the tokens it actually uses, input and output at their own rates. Prices follow the bitcoin price and include our 10% margin over the upstream provider. Cached input tokens (the long context an agent resends) are debited at the provider's cache price: a tenth of the input price for Kimi, GLM 5.2/5.3 and DeepSeek V4 Pro, about a fifth for the Flash models and Nemotron. Models without a pi402 name are sold to plain L402 clients for now.

From Claude, Cursor or any MCP client

Let your assistant call Kimi, GLM or DeepSeek and pay in sats, through the fetch_l402 tool of Alby's MCP server. Lampo's 402 responses work with Alby's L402 client.

  1. In a Lightning wallet that supports Nostr Wallet Connect (for example Alby Hub or Coinos), create a connection with a small budget, such as 5,000 sats. Keep the connection string secret: it can spend up to that budget.
  2. Add the MCP server, running locally. Claude Desktop (claude_desktop_config.json): 
    {"mcpServers": {"alby": {"command": "npx", "args": ["-y", "@getalby/mcp"],
  "env": {"NWC_CONNECTION_STRING": "nostr+walletconnect://..."}}}}
    Claude Code: claude mcp add alby -e NWC_CONNECTION_STRING="nostr+walletconnect://..." -- npx -y @getalby/mcp
  3. Ask, for example: Use fetch_l402 to POST to https://lampo.run/v1/chat/completions with body {"model":"deepseek-ai/DeepSeek-V4-Flash-0731","messages":[{"role":"user","content":"Summarize this file in 5 bullets: ..."}]}. The first call buys a bundle (1,000 sats for this model); the next ones reuse it. Stick to one model per session.

How it works

  1. Your agent sends a normal OpenAI-style request. Lampo answers 402 Payment Required with a Lightning invoice for one bundle.
  2. The pi402 wallet pays it within your spending limits and retries with the proof of payment.
  3. The response streams back. The same credential keeps working until the bundle is used up.

From your own code or agent (plain HTTP)

Any client that speaks L402, or the Payment HTTP scheme (MPP), can buy. Model ids and live prices are at /v1/models; GET /v1/balance with the same Authorization header shows the tokens left.

# 1. Ask: you get 402 with a Lightning invoice and a macaroon
curl -si https://lampo.run/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731","messages":[{"role":"user","content":"hi"}]}'
# WWW-Authenticate: L402 macaroon="AgEE...", invoice="lnbc6u1..."

# 2. Pay the invoice with any Lightning wallet and keep the preimage

# 3. Repeat the request with the credential; reuse it until the bundle runs out
curl https://lampo.run/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -H "Authorization: L402 $MACAROON:$PREIMAGE" \
  -d '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731","stream":true,"messages":[{"role":"user","content":"hi"}]}'

Questions

Who runs Lampo?

An independent operator in Italy (details in the terms). The whole setup is open source: github.com/lamporun/lampo. Lampo is not affiliated with Lightning Labs, Baseten or the model makers.

How much is 1,000 sats?

Around $0.60 at today's bitcoin price. Prices in sats follow the bitcoin price and are recalculated every 10 minutes; the table above is always current.

What if something fails after I pay?

Your bundle is not lost: the same credential keeps working until its tokens are used up, so just retry. If something breaks on our side, write to contact@lampo.run.

Do you keep my prompts?

No. We store only token counts and payments. The models run on Baseten's servers in the US, which process the request to answer it.

Which wallet do I need?

For pi402, its built-in wallet: fund it from any Lightning wallet. From your own code, any Lightning wallet that gives you the payment preimage, or an L402/MPP client. Keep at least 2,000 sats in a Wavelength wallet.

Where is it available?

Everywhere Lightning works, except countries under comprehensive EU sanctions. Lampo is meant for developers and businesses.

Good to know

  • Answers are generated by AI models (Moonshot Kimi, Z.ai GLM, DeepSeek, NVIDIA Nemotron) and can be wrong. You are talking to software, not to a person.
  • We do not store your prompts or responses: only token counts and payments.
  • Payments are final. If something breaks on our side, write to us.
  • Paying an invoice means accepting the Terms. Lampo is meant for developers and businesses, and is not available in countries under comprehensive EU sanctions.
  • pi402 and the Wavelength wallet are new software marked alpha by their authors. Keep small balances.
