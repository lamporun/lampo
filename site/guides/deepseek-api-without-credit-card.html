Use the DeepSeek API without a credit card or account

Most AI APIs want an account and an international card before the first request. Lampo sells DeepSeek V4 Flash and DeepSeek V4 Pro (plus Kimi, GLM and Nemotron) through an OpenAI-compatible API that you pay per use over the Bitcoin Lightning Network.

What you need

  • A Lightning wallet that supports Nostr Wallet Connect (NWC), for example Alby Hub or Coinos. Create a connection with a small spending budget.
  • Node.js, to run Alby's command-line tool with npx.

Step by step

  1. Connect your wallet once (the connection string is secret: it can spend up to its budget): 
    npx -y @getalby/cli@0.10.2 connect "nostr+walletconnect://..."
  2. Check the price without paying: 
    npx -y @getalby/cli@0.10.2 fetch "https://lampo.run/v1/chat/completions" -X POST \
  -H '{"Content-Type":"application/json"}' \
  -b '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731","messages":[{"role":"user","content":"hi"}]}' --dry-run
  3. Make the real call. The first one pays for a bundle of tokens: 
    npx -y @getalby/cli@0.10.2 fetch "https://lampo.run/v1/chat/completions" \
  -X POST -H '{"Content-Type":"application/json"}' \
  -b '{"model":"deepseek-ai/DeepSeek-V4-Flash-0731","stream":false,"messages":[{"role":"user","content":"Explain recursion in two sentences."}]}' \
  --max-amount 1000 --currency BTC --unit sats --network lightning -o reply.json
  4. The answer is in reply.json, under choices[0].message.content. The command also prints a reusable credentials value: pass it back with --credentials and the next calls use the same bundle instead of paying again.

Which DeepSeek model?

  • deepseek-ai/DeepSeek-V4-Flash-0731: fast and cheap, 1M-token context. Good for most tasks.
  • deepseek-ai/DeepSeek-V4-Pro-0813: stronger reasoning, 1M-token context, larger bundle.

The models are open-weight versions run by Baseten in the United States. Lampo does not store your prompts or answers.

Live prices: lampo.run shows every model and bundle, updated every 10 minutes. The cheapest bundle is 1,000 sats (about $0.60) for about 2.8 million tokens of DeepSeek V4 Flash.
